# AGENTS.md — Контракт разработки проекта Recording & Obsidian Automation

## 1. Tech Stack
- **Язык:** Python 3.12+
- **Пакетный менеджер:** `uv`
- **Графический интерфейс:** `customtkinter` (Dark/System theme)
- **ИИ-распознавание аудио:** `faster-whisper` (движок CTranslate2, ускорение NVIDIA CUDA 12, cuDNN 9)
- **Обработка медиа:** `ffmpeg-python`, системный бинарник `ffmpeg`
- **Целевая среда базы знаний:** Obsidian Vault (Markdown, KaTeX LaTeX, Canvas JSON, Zettelkasten)

## 2. Commands
- **Установка зависимостей:** `uv pip install -r requirements.txt` или `uv sync`
- **Запуск графического транскрибатора:** `uv run python app_gui.py` (или `Запустить_Транскрибатор.bat`)
- **Консольная экстракция видео:** `uv run python src/extract.py "<video_path>"`
- **Синтаксическая компиляция:** `uv run python -m py_compile app_gui.py src/extract.py`
- **Запуск тестов:** `uv run pytest` (или `uv run python -m unittest discover tests`)
- **Генерация AST-карты кодовой базы:** `npx repomix`

## 3. Code Standards & Quality Gates
- **Язык общения и документации:**
  - Все ответы в чате, пояснения, docstrings и комментарии внутри кода — **строго на русском языке**.
  - Все Git commit messages и PR — **строго на русском языке** по стандарту Conventional Commits (`feat: ...`, `fix: ...`, `chore: ...`).
  - Все имена переменных, функций, классов и модулей — строго на английском языке.
- **Архитектура чистого кода:**
  - **Ранние возвраты (Early Returns):** избегать вложенности условий более 3 уровней.
  - **Компактные функции:** размер функции не должен превышать 30–40 строк. Разбивать сложную логику на вспомогательные чистые функции.
  - **Строгая типизация:** полный запрет на неявные типы и `any`. Обязательные type hints для параметров и возвращаемых значений.
  - **Без заглушек:** запрещены комментарии-заглушки вида `// TODO` или нереализованные моки. Код обязан быть рабочим и законченным.

### Ключевые инварианты конвейера:
1. **Строгая точность (Strict Fidelity):** фиксация только реальных тезисов преподавателя. Запрет на додумывание определений.
2. **Фильтрация "воды" (Remove Fluff):** удаление посторонних тем, оффтопа и повторов при сохранении максимальной плотности полезной теории.
3. **Исключение для математики:** для дисциплин с формулами (Алгебра, Матанализ, Дискретная математика) агент обязан добавлять понятные пояснения и примеры.
4. **Мультимодальный анализ слайдов (Multimodal Inspection):** агент ОБЯЗАН открывать и изучать кадры из `cache/<video>/frames/` через `view_file` (особенно при математических выкладках, коде, таблицах и ссылках лектора на экран).
5. **Запрет встраивания "сырых" картинок:** запрещено вставлять скриншоты в саму итоговую заметку (`![[frame.jpg]]`). Формулы и доказательства со слайдов переводятся в академический KaTeX LaTeX (`$$...$$`), схемы — в Mermaid, код — в блоки кода.
6. **Сквозная актуализация:** каждая обработанная лекция дополняет Zettelkasten-термины (`Термины/`), генерирует лекционную заметку, пополняет монолитный `Учебник - <Subject>.md`, обновляет граф `<Subject>.canvas` и фиксируется в `PROCESSED_VIDEOS.md`.
7. **Автоматическое переименование:** видеозаписи с неинформативными именами дат (например, `2026-09-14 10-37-07.mp4`) после анализа переименовываются в читаемый вид (например, `Основы проектной деятельности. Лекция 1.mp4`).
8. **Аббревиатуры дисциплин в именах заметок:** все заметки лекций и практик ОБЯЗАНЫ начинаться с префикса `<АББРЕВИАТУРА> - ...` (`АДиИИ`, `АГиТДУ`, `ДМ`, `ИнЯз`, `ИТиС`, `МатАн`, `ОПД`, `ОРГ`, `ПФК`, `ПРОГ`). Подробнее в [obsidian_vault.md](file:///C:/Users/denis/Documents/antigravity/recording/docs/architecture/obsidian_vault.md).
9. **Синхронная миграция без потери связей:** при первом контакте с дисциплиной агент аккуратно приводит старые заметки к стандарту аббревиатур, каскадно обновляя ВСЕ входящие ссылки `[[...]]` в терминах, учебниках, графах Canvas и реестре без единой битой ссылки. Любые появляющиеся заметки непрерывно поддерживаются в соответствии с утвержденным стандартом.
10. **Активное припоминание (Active Recall):** каждая лекция обязана завершаться разделом `## ❓ Вопросы для экзамена и самопроверки` с краткими тезисными ответами под сворачиваемым спойлером `> [!question]- Ответ`.
11. **Фиксация дедлайнов и ДЗ:** озвученные преподавателем домашние задания и сроки сдачи лабораторных работ фиксируются в централизованном файле `Дедлайны и ДЗ.md`.
12. **Самопроверка ссылок (Self-Linting):** перед финальным отчётом агент обязан проверить все новые и затронутые заметки на отсутствие битых ссылок `[[...]]`.
13. **Изоляция скриптов (Zero-Trash Policy):** категорически запрещено создавать одноразовые скрипты (`make_*.py`, `temp_*.py`) в корне проекта. Все временные утилиты создаются строго в папке `scratch/` и удаляются после выполнения.

## 5. Prohibited Patterns & Safety
- **Запрет мусорных файлов в корне:** запрещено сохранять временные скрипты и отчеты в корневой каталог проекта. Использовать только папку `scratch/`.
- **Запрет деструктивных действий:** запрещено без прямого подтверждения пользователя удалять каталоги вне временных кэшей (`cache/`), сбрасывать Git (`git reset --hard`) или перезаписывать готовые заметки.
- **Защита секретов:** запрещено хардкодить пути к чувствительным ресурсам или токены. Все настройки хранятся в `.env`.
- **Защита системных путей:** запрещено модифицировать файлы операционной системы Windows.
